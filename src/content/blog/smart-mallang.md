졸업 프로젝트로 MZ스럽게 **스마트 말랑이**를 제안했고, 최종적으로 채택됐다 ㅎㅎ 우리 과는 기계트랙, 의생명공학트랙, 바이오데이터 트랙을 이수하는 학생들이 섞여 있긴 하지만 과의 근간이 기계트랙에 있다보니 그냥 앱 하나, 프로그램 하나보다는 물리적인 산출물이 하나 있어야 한다. 그래서 가정용 손 운동·재활 보조 기능을 넣은 스마트 말랑이가 좋을 것 같았다. 손에 쥐는 말랑이에 센서와 경도 조절 구조를 넣고, 운동 기록을 스마트폰 앱으로 확인할 수 있도록 만들었다.

기존 말랑이처럼 간단하게 사용하면서도 **어느 손가락을 얼마나 사용했는지, 얼마나 일정하게 반복했는지**를 데이터로 남기는 것이 목표였다. 그냥 쥐고 끝나는 운동에서, 내가 어떻게 운동했는지 확인할 수 있는 도구를 만들어 보고 싶었다.

내가 맡은 부분은 **전반적인 파이프라인과 앱 개발**이었다. 손가락별 센서 입력이 운동 기록과 사용자 피드백으로 이어지는 흐름을 중심으로 참여했다. 센서값이 앱에 도착하는 데서 끝나는 게 아니라, 그 값으로 반복을 구분하고 세션을 기록한 뒤 사용자가 이해할 수 있는 결과로 보여주는 흐름을 연결했다. 하드웨어와 사용자 평가는 팀원들과 함께 진행한 프로젝트의 일부다.

### 손 운동 도구에 부족했던 피드백

말랑이나 퍼티형 도구는 저렴하고 별도의 착용 과정 없이 쓸 수 있다. 하지만 운동을 마친 뒤 남는 정보가 적다. 몇 번 쥐었는지, 목표 시간만큼 힘을 유지했는지, 특정 손가락에만 힘이 몰리지는 않았는지 확인하기 어렵다.

스마트 말랑이는 이 간극을 줄이기 위한 프로젝트였다. 임상 장비 수준의 절대 악력을 측정하기보다, **개인 기준선 대비 상대적인 압력 변화와 반복 패턴을 기록하는 저비용 도구**를 목표로 했다.

### 설계 요구조건부터 정리하기

| 요구조건 | 설계 방향 |
| --- | --- |
| 간단한 사용 | 한 손에 쥐기 쉬운 말랑한 외피, 복잡한 착용 과정 최소화 |
| 손가락별 측정 | 다섯 손가락 위치에 독립적인 압력 패드 배치 |
| 수행 기록 | 반복 횟수, 유지시간, 압력 피크와 파형 기록 |
| 난이도 조절 | 쉬움·보통·어려움의 3단계 경도 |
| 앱 피드백 | 실시간 값, 세션 결과, 손가락별 지표, 난이도 추천 |
| 제작 비용 | 30만 원 이내 |

핵심은 센서를 넣는 것뿐 아니라, 센서가 들어간 뒤에도 사용자가 편하게 쥘 수 있게 만드는 일이었다. 외피·센서·에어백은 같은 공간에 들어가므로 측정과 촉감, 조절 구조를 함께 고려해야 했다.

### 왜 Velostat와 에어백을 선택했나

팀에서는 세 가지 설계를 비교했다.

| 설계안 | 장점 | 주요 부담 |
| --- | --- | --- |
| Velostat 5채널 센서 + 에어백 | 낮은 비용, 곡면 배치, 경도 조절과 개별 손가락 기록의 결합 | 센서 위치·반복 사용에 따른 편차, 누기 가능성 |
| 상용 FSR 센서 + 교체형 경도 패드 | 비교적 일정한 센서 품질, 단순한 구조 | 여러 센서의 비용, 곡면 배치, 수동 패드 교체 |
| 공압 챔버 + 압력센서 | 공기압 중심의 측정과 경도 조절 | 여러 챔버 제작, 누기·간섭, 손가락별 간접 측정 |

사용 편의성·비용·측정·난이도 조절·앱 피드백·제작 가능성을 각각 5점으로 평가한 내부 설계 비교에서 첫 번째 안이 **28/30점**으로 선택되었다. 다른 안은 각각 22점, 20점이었다. 우리가 정한 예산과 제작 조건 안에서는 센서 배치, 경도 조절, 앱 연결을 함께 구현하기에 이 안이 가장 적합하다고 판단했다.

### 시제품의 데이터 흐름

```text
손으로 말랑이 쥐기
  → 손가락 위치의 압력 센서 5개
  → 제어부에서 센서값 읽기
  → BLE로 스마트폰 앱에 전달
  → 반복·유지시간·피크·파형과 세션 결과 표시

내부 에어백 + 미니 펌프
  → 3단계 경도 조절
```

엄지부터 소지까지 닿는 위치에 패드를 배치하고, 사용자가 쥘 때 각 채널의 변화가 따로 보이도록 구성했다. 앱에서는 연속 횟수와 경과 시간, 손가락별 압력과 평균 피크, 운동 점수, 난이도 추천, 일별 세션 기록을 확인할 수 있다.

이때 센서값은 **보정된 뉴턴 단위의 절대 힘이나 임상 악력 검사값과 동일하지 않다.** 같은 힘으로 눌러도 손가락이 센서 중심에서 벗어나면 값이 달라질 수 있으므로, 착지 위치와 개인 기준선을 고려해야 한다.

### 운동 점수는 무엇을 뜻하나

횟수만 세면 빠르게 여러 번 쥐는 동작과 일정한 힘을 유지하는 동작을 구분하기 어렵다. 유효 사이클마다 유지시간, 반복 시작 간격, 압력 피크를 이용해 수행을 요약했다.

- **유지시간:** 기본 목표인 3초와 실제 유지시간 사이의 오차를 반영한다. 평균 오차가 1초이면 30점 감점하도록 설계했다.
- **리듬:** 반복 간격의 변동계수(CV)를 사용해 시간적 일관성을 본다.
- **강도:** 압력 피크의 변동계수로 반복마다 비슷한 세기를 유지했는지 본다. 힘이 클수록 무조건 높은 점수가 되는 구조는 아니다.

CV는 표준편차를 평균으로 나눈 값으로, 평균이 충분히 0에서 떨어져 있을 때 상대적인 변동 정도를 요약한다. 각 점수는 0–100 범위로 제한하고 종합하며, 유지시간에 가장 높은 가중치인 0.5를 부여했다.

손가락별로는 전체 입력 중 기여도와 가장 강하게 사용한 손가락 대비 상대 활성도를 함께 산출하고, 수행 패턴을 weak·pinch·partial grip·full grip으로 나누는 구조를 제시했다. 이러한 점수와 라벨은 **시제품에서 정한 수행 요약 규칙**이다. 손 기능 회복 정도를 판정하는 임상 척도로 검증된 것은 아니다.

### 기능 검증: 동작 여부와 체감 차이는 별개였다

실내에서 스마트폰을 책상에 두고, 앉아서 한 손으로 쥐는 상황을 가정해 기능을 확인했다. 10회 반복 후 실제 횟수와 앱 기록을 비교하고, 전체 쥐기와 특정 손가락 중심의 쥐기에서 파형이 달라지는지 살폈다.

| 검증 항목 | 결과 |
| --- | --- |
| 반복 횟수 검출: 실제 수행과 90% 이상 일치 기준 | 만족 |
| 손가락별 압력 파형 차이 | 만족 |
| 세션 로그 저장 | 만족 |
| 수행 차이의 운동 점수 반영 | 만족 |
| 경도 3단계 구분 | 부분 만족 |

경도는 세 단계로 조절되었지만 모든 인접 단계의 차이가 뚜렷하지는 않았다. 1단계와 3단계 차이에 비해 1–2, 2–3단계 구분은 사용자마다 달랐다. 펌프를 제어하는 값이 달라졌다는 사실과 사람이 저항감을 구별할 수 있다는 사실은 서로 다른 검증 대상이었다.

### 대학생 10명 대상 사용성 평가

초기 사용성과 촉감, 앱 화면 이해도, 경도 차이를 보기 위해 **20대 대학생 10명**이 세 단계 경도를 순서대로 체험하고 짧은 세션을 수행했다. 이후 5점 척도 설문에 응답했다.

| 설문 문항 | 점수 / 5 |
| --- | --- |
| 경도 조절이 1–3단계로 잘 구현되었는가? | 3.5 |
| 피드백 화면이 사용자 친화적인가? | 4.1 |
| 기존 말랑이의 촉감이 유지되는가? | 4.2 |

별도 장갑이나 착용 과정 없이 바로 쥘 수 있다는 점, 앱에서 수행 상태를 볼 수 있다는 점이 긍정적인 피드백이었다. 반면 경도 간 차이를 더 명확히 해 달라는 의견도 있었다.

이 평가는 **건강한 성인의 초기 사용성 평가**다. 실제 손 기능 저하 환자나 고령층 대상 시험, 치료 효과 검증, 장기 사용 평가와는 구분해야 한다. 표본이 작고 단계 체험 순서도 고정되어 있어 결과를 넓게 일반화하기 어렵다.

### 구현하면서 드러난 개선점

**1. 센서값이 흔들리면 점수도 흔들린다.** 손가락 위치를 일정하게 유도하는 외피와 사용 전 영점 보정이 필요하다. 다음 버전에서는 사용 전 캘리브레이션을 앱의 시작 흐름에 넣어 보고 싶다.

**2. 반복의 시작과 끝을 정의해야 한다.** 빠르게 쥐거나 힘을 완전히 빼지 않으면 사이클 경계가 모호해진다. 상승·하강 임계값을 다르게 두는 슈미트 트리거 방식은 이를 개선하기 위한 제안이다.

**3. 경도는 실제 압력으로 제어할 필요가 있다.** 외피 탄성, 에어백 위치, 공기량, 사용자 악력이 모두 체감에 영향을 준다. 펌프 작동 시간에만 의존하는 대신 기압센서로 내부 압력을 측정하고 목표에서 멈추는 폐루프 제어가 후속 과제다.

**4. 점수가 다음 행동으로 이어져야 한다.** 그래프와 숫자에 익숙하지 않은 사용자에게는 '유지시간이 부족합니다', '리듬이 불안정합니다' 같은 문장형 피드백이 도움이 될 수 있다. 앱을 더 다듬는다면 점수 옆에 다음 세션에서 바꿔 볼 행동을 함께 제시하고 싶다.

### 졸업프로젝트를 마치며

최종 제작비는 **약 15만 원**으로, 처음 잡았던 30만 원 안에 시제품을 만들었다. 손가락별 압력 입력부터 BLE 통신, 세션 기록과 피드백까지 연결했고, 사용자 평가에서는 앱 화면의 친화성이 4.1점, 촉감 유지가 4.2점이었다.

앱 개발 입장에서 남은 질문은 '값을 얼마나 많이 보여줄까'보다 **'이 화면을 보고 다음 운동에서 무엇을 바꿀 수 있을까'**에 가깝다. 손가락별 그래프와 점수는 만들었지만, 그걸 바로 이해하고 행동으로 옮길 수 있게 하는 데에는 더 손볼 부분이 있었다.

하드웨어도 마찬가지였다. 경도를 3단계로 나눴다고 해서 사용자가 세 단계를 똑같이 구별하는 것은 아니었다. 경도 평가가 3.5점에 머문 점은 다음 버전에서 가장 먼저 개선하고 싶은 부분이다. 공기압을 직접 측정하는 제어 방식과 손가락 위치를 유도하는 외피를 적용하면 측정과 사용감 모두를 더 안정적으로 만들 수 있을 것 같다.

이번에는 건강한 대학생을 대상으로 초기 사용성을 확인했다. 실제 환자와 고령층에서 얼마나 편하게 쓸 수 있는지, 장기간 사용해도 센서와 에어백이 견디는지, 재활에 어떤 도움이 되는지는 더 검증해야 한다.

익숙한 말랑이를 센서와 앱으로 연결하면서, 하드웨어의 작은 차이가 데이터와 화면까지 이어진다는 걸 구체적으로 볼 수 있었다. 다음에 비슷한 디바이스를 만든다면 데이터가 들어오는 순간뿐 아니라, 사용자가 잡는 위치와 결과를 읽는 순간까지 한 흐름으로 설계하고 싶다.
